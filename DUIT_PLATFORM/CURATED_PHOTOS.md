# DUIT — финальная кураторская фото-схема

В финальной демо-сборке каталог намеренно сокращён до 15 направлений в 4 городах.
Это 60 демо-услуг и 60 разных исходных фотографий.

## Почему каталог уменьшен

Ранние версии использовали поисковые фотосервисы по ключевым словам. Даже при точных тегах внешний сервис мог вернуть нерелевантный кадр: например кота для барбера или садовый инструмент для сантехники.

В этой версии случайный поиск фотографий полностью отключён.

## Правила

- каждая категория имеет список из 4 вручную проверенных Pexels photo ID;
- один photo ID используется ровно один раз во всём демо-каталоге;
- один город + одно направление = одна демо-услуга;
- `LoremFlickr` не используется;
- фото соседних категорий не смешиваются;
- аватары исполнителей уникальны и разделены по полу имени;
- `audit_demo_media` проверяет эти правила автоматически.

Пользовательские фотографии по-прежнему загружаются локально в `media/` и имеют приоритет над демо-обложкой.
