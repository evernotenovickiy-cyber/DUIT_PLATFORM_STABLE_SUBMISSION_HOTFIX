# DUIT FINAL AUDIT

Финальная сборка перед сдачей.

## Критичные проверки

- Django migrations включены.
- Windows launcher/verify — ASCII + CRLF.
- Регистрация, вход, роли, кабинет, услуги, заказы, сообщения, отзывы и demo-payments сохранены.
- Фото услуг переведены на строгую схему **15/15 curated fixed-photo pools**.
- Ни одна услуга не имеет fallback на соседнюю крупную сферу.
- 123 категории = 123 отдельных фотопула, по 4 точных профессиональных запроса в каждом.
- `audit_demo_media` падает при отсутствии хотя бы одного пула, неправильном category marker, повторе URL, повторе аватара или несовпадении пола имени/портрета.
- Demo URL детерминированы через `lock`: обычный перезапуск не меняет картинки.

См. `PHOTO_POOLS_123.md`.
