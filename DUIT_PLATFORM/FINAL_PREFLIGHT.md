# DUIT — final preflight

Финальная проверка перед передачей преподавателю.

1. На машине с интернетом выполнить `prepare_submission.bat`.
2. Скрипт обязан пройти Django check, проверку миграций, media audit и весь test suite.
3. Передавать преподавателю созданный `DUIT_PLATFORM_OFFLINE_SUBMISSION.zip`.
4. В архиве должны присутствовать 60 локальных фото услуг и 60 локальных аватаров.
5. После распаковки проверить `verify_windows.bat`, затем `start_windows.bat`.
6. Ручной smoke path: регистрация → вход → профиль → услуга с фото → поиск → избранное → чат → заказ → DUIT Pay → статусы → отзыв.
7. Мобильный smoke path: 375 px — burger, поиск, каталог, карточка услуги, кабинет, чат, checkout.

Финальный каталог намеренно ограничен 15 направлениями и 4 городами: приоритет отдан качеству, стабильности и семантически корректным фото вместо искусственно большого каталога.
