# DUIT — финальная перепроверка перед сдачей

Эта сборка дополнительно проверена после добавления DUIT Pay и мобильного burger-меню.

## Что перепроверено

- регистрация, роли и вход по email/логину;
- кабинет заказчика и исполнителя;
- создание/редактирование/архивация услуги;
- загрузка до 6 фотографий;
- каталог, поиск, категории, города, фильтры и пагинация;
- избранное;
- чат и непрочитанные сообщения;
- заказ, дата/время, статусы и ограничения переходов;
- DUIT Pay: успех, отказ, после выполнения, возврат;
- отзыв только после завершённого заказа;
- журнал;
- мобильная навигация и мобильный поиск;
- Docker-схема с внутренним PostgreSQL.

## Дополнительные исправления последнего аудита

1. Исполнитель при покупке чужой услуги автоматически становится универсальным аккаунтом.
2. Отменённый/возвращённый заказ нельзя оплатить повторно.
3. Удаление услуги с историей заказов теперь архивирует её вместо ошибки `ProtectedError`.
4. В мессенджере выводятся реальные display-name и аватар профиля.
5. Генерация 200 демо-исполнителей использует уникальные ФИО.
6. Пул демонстрационных фото расширен за счёт сочетания фото направления и сферы.
7. Добавлены 404/500 страницы.

## Перед защитой

На Windows обязательно выполнить `verify_windows.bat`. Только результат `DUIT verification PASSED.` считается интеграционной проверкой окружения. Затем выполнить один ручной сценарий: регистрация → услуга → поиск → заказ → оплата → сообщение → смена статусов → отзыв.
