# DUIT — offline submission

Чтобы сделать демонстрационный визуал полностью независимым от внешних фотосервисов:

1. Запустите `prepare_submission.bat` на компьютере с интернетом.
2. Дождитесь `OFFLINE submission package is READY`.
3. Рядом с папкой проекта появится `DUIT_PLATFORM_OFFLINE_SUBMISSION.zip`.
4. Этот ZIP уже содержит 60 локальных фотографий услуг и 60 локальных портретов исполнителей.
5. На компьютере преподавателя проект использует `/static/demo/...` и не обращается к Pexels/RandomUser для демо-каталога.

`verify_windows.bat` и `start_windows.bat` также автоматически докачивают отсутствующий demo-media cache, если запуск происходит впервые и интернет доступен.

> Примечание: автономность относится к demo-media. Для первой установки Python-зависимостей всё равно нужен локальный pip-cache или интернет; при Docker-запуске образ PostgreSQL/Python также должен быть уже закэширован или доступен для загрузки.
